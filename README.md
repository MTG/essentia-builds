# Docker images for portable builds of Essentia

Docker images for building portable [`manylinux`](https://github.com/pypa/manylinux) Python wheels and executables for Essentia.

Image repositories:
- https://github.com/orgs/MTG/packages (used in Essentia CI)
- https://hub.docker.com/r/mtgupf/essentia-builds

The provided images are based on the official [`manylinux`](https://github.com/pypa/manylinux) images and include all pre-requisites and dependencies for building Essentia.
